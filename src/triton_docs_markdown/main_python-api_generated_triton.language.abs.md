# triton.language.abs¶

triton.language.abs(_x_ , __semantic =None_)¶
    

Computes the element-wise absolute value of `x`.

Parameters:
    

**x** (_Block_) – the input values

This function can also be called as a member function on [`tensor`](triton.language.tensor.html#triton.language.tensor "triton.language.tensor"), as `x.abs()` instead of `abs(x)`.
