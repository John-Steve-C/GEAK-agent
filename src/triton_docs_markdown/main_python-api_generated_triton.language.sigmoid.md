# triton.language.sigmoid¶

triton.language.sigmoid(_x_)¶
    

Computes the element-wise sigmoid of `x`.

Parameters:
    

**x** (_Block_) – the input values

This function can also be called as a member function on [`tensor`](triton.language.tensor.html#triton.language.tensor "triton.language.tensor"), as `x.sigmoid(...)` instead of `sigmoid(x, ...)`.
