# Welcome to Triton’s documentation!¶

[Triton](https://github.com/triton-lang/triton) is a language and compiler for parallel programming. It aims to provide a Python-based programming environment for productively writing custom DNN compute kernels capable of running at maximal throughput on modern GPU hardware.

## Getting Started¶

  * Follow the [installation instructions](getting-started/installation.html) for your platform of choice.

  * Take a look at the [tutorials](getting-started/tutorials/index.html) to learn how to write your first Triton program.
