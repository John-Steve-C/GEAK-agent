# triton.language.flip¶

triton.language.flip(_x_ , _dim =None_)¶
    

Flips a tensor x along the dimension dim.

Parameters:
    

  * **x** (_Block_) – the first input tensor

  * **dim** (_int_) – the dimension to flip along




This function can also be called as a member function on [`tensor`](triton.language.tensor.html#triton.language.tensor "triton.language.tensor"), as `x.flip(...)` instead of `flip(x, ...)`.
